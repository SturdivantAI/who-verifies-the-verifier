# Data

The verdict corpus is not committed to this repository. Retrieve it from
the source:

    https://huggingface.co/datasets/ICML-2026-agent-repro/verdicts

Expected local path for the analysis scripts:

    data/icml2026-verdicts/verdicts.json

The corpus is approximately 25 MB and holds 6,398 reproduction runs
carrying 32,688 claim-level verdicts. Every run has a `judged_at`
timestamp; the verdicts analysed here were issued between
2026-07-08T08:39:09Z and 2026-08-02T01:51:05Z.

The corpus is the work of the 2026 ICML Agent Reproduction Challenge
organizers and is subject to the source dataset's own terms, not the MIT
license covering this repository. See the provenance section of the
top-level README.
